# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-20

### Added
- Core todo item creation, completion toggle, and deletion
- LocalStorage persistence for task data
- Active task counter showing remaining items
- All / Active / Completed filter views
- Clear completed tasks functionality
- Responsive mobile-friendly UI layout
- Development and production environment configuration
- GitHub Actions deployment pipeline
- Full Git Flow branching structure
