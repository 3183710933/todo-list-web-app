# Todo List Web Application

A lightweight, client-side todo list application built with vanilla HTML, CSS and JavaScript. Features include task creation, completion toggle, deletion, filtering, and localStorage persistence.

## Features

- Create new todo items
- Mark tasks as complete / incomplete
- Delete individual tasks
- Filter by All / Active / Completed
- Clear all completed tasks
- LocalStorage persistence across browser sessions
- Responsive mobile-friendly design

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript (ES6+)
- Git + GitHub for version control
- GitHub Actions for CI/CD
- Static web hosting

## Branching Strategy

This project follows a Git Flow branching model:

- `main` — production-ready releases
- `develop` — integration branch
- `feature/*` — individual feature development branches

## Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. No build step required

## Deployment

Merges to `main` trigger the GitHub Actions deployment pipeline automatically.
